# TourSafe B2G Dashboard

MERN-stack authority dashboard with Mapbox GL JS.

## Responsibilities

- Agency login and JWT sessions.
- Live map with traveler positions and geo-fences.
- Real-time incident feed via Socket.io.
- e-FIR generation and dispatch.
- QR scan responder interface.
- Incident heatmaps and analytics.
