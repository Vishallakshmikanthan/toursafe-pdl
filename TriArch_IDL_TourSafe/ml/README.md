# TourSafe ML Engine

LSTM Autoencoder training, evaluation, and ONNX export.

## Responsibilities

- Collect and preprocess normal activity datasets.
- Train Sequence-to-Sequence LSTM Autoencoder.
- Calibrate anomaly threshold at 99.5th percentile.
- Export model to ONNX.
- Validate ONNX parity with TensorFlow.
- (Stretch) Implement SNN-CAD trajectory anomaly detection.
