# TourSafe Tests

Cross-module, integration, load, and hardware validation tests.

## Structure

- `unit/` — language-specific unit tests (also inside each module).
- `integration/` — end-to-end flow tests.
- `load/` — Locust scenarios.
- `data/` — demo and test datasets.
- `hardware/` — hardware validation scripts and logs.
