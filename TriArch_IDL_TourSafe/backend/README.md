# TourSafe Backend

FastAPI + Python real-time telemetry and ML inference engine.

## Responsibilities

- WebSocket telemetry ingestion.
- Redis live GPS cache.
- MongoDB persistence.
- ONNX Runtime LSTM inference.
- Anomaly confirmation and incident emission.
- REST API for dashboard.
- Offline-queue reconciliation.
- e-FIR trigger integration.
