# TourSafe Mobile App

React Native + TypeScript traveler application.

## Responsibilities

- 50Hz IMU + 1Hz GPS sensor collection.
- A_mag computation and sliding window generation.
- SQLite offline telemetry queue with AES-256 encryption.
- Turf.js geo-fence evaluation.
- DID wallet + QR code display.
- Manual SOS override.
