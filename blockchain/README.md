# TourSafe Blockchain / DID

Solidity smart contracts and Hardhat development environment for TourSafe's Self-Sovereign Identity layer.

## Responsibilities

- Identity Resolution Contract.
- DID registration, resolution, emergency access grant/revoke.
- Deployment to Polygon Amoy and mainnet.
- Key management patterns for traveler and agency keys.
